# UX Design Validation

## Overview

The UX designs for the Sign-Up and Login functionality were reviewed against the documented Sprint 1 requirements.

The purpose of this review was to confirm that the proposed designs align with the requirements before they are handed over for development.

## Validation Findings

### 1. Login Terminology

**Status:** Changes Required

The UX design currently uses the term **“Sign in”**.

The documented requirements use **“Log in”** for existing users accessing their account.

The wording should therefore be changed from **“Sign in”** to **“Log in”** to maintain consistency with the requirements.

## Validation Outcome

The overall UX design aligns with the intended authentication functionality, but the identified changes should be made before the design is finalised.

The UX designer should:
- Replace **“Sign in”** with **“Log in”** to match the documented requirements.

Once these changes have been made, the updated designs can be handed over to the developers for implementation.
