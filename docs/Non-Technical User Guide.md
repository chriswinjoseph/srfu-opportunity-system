# Non-Technical User Guide

## 1. Purpose

This guide explains how to use the Safe Roads For Us Opportunity System to manage organisations, prepare outreach emails, record responses and track contact status.

## 2. User Roles

The system has two user roles:

- **Admin:** Can add and edit organisations, manage users, review drafts, approve or reject drafts, and send approved emails.
- **Staff:** Can view organisations, prepare and edit drafts, submit drafts for approval, and send drafts after Admin approval.

Staff users will not see Admin-only controls.

## 3. Logging In

1. Open the system’s login page.
2. Enter your email address.
3. Enter your password.
4. Select **Log In**.
5. The dashboard will open after a successful login.

If your details are incorrect, check your email address and password, then try again.

## 4. Logging Out

1. Select **Log Out** in the top-right corner.
2. Your session will end.
3. You will return to the login page.

Always log out when using a shared computer.

## 5. Using the Dashboard

The dashboard groups organisations by contact status:

- **Not Yet Contacted:** An outreach email has not been sent successfully.
- **Contacted:** An outreach email has been sent successfully.

### Searching for an Organisation

1. Open the dashboard.
2. Select the search box.
3. Enter the organisation’s name.
4. Review the matching results.
5. Clear the search box to show all organisations again.

### Filtering Organisations

1. Open the dashboard.
2. Select the filter you need.
3. Choose an available option, such as organisation type, region or contact status.
4. Review the filtered results.
5. Clear or reset the filters to show all records again.

### Viewing Organisation Details

1. Find the organisation on the dashboard.
2. Select **View Details**.
3. Review its contact information, contact status, response outcome and email history.
4. Return to the dashboard when finished.

Check the organisation’s history before preparing another email to avoid duplicate outreach.

## 6. Adding an Organisation

Only an Admin can manually add an organisation.

1. Select **Add Organisation**.
2. Choose the organisation type: **Bank**, **Branch** or **Club**.
3. Enter the required information.
4. If you are adding a branch, select its parent bank.
5. Add any available contact information.
6. Review the information.
7. Select **Submit**.

A new organisation starts with the status **Not Yet Contacted**. Adding a contact name or email address does not mean the organisation has been contacted.

### Missing or Invalid Information

1. The organisation will not be saved.
2. A message will appear beside the affected field.
3. Correct the information.
4. Select **Submit** again.

### Exact Duplicate

If the organisation already exists:

1. The new record will not be created.
2. The system will show the existing organisation.
3. Open and review that record instead of creating another one.

### Possible Duplicate

If the organisation is similar to an existing record:

1. The system will show a **Possible duplicate found** warning.
2. Review the matching organisation.
3. Select **Cancel** if it is the same organisation.
4. Select **Continue Anyway** only if you are sure they are different organisations.

## 7. Recording a Positive Response

When a bank responds positively:

1. Search for the bank on the dashboard.
2. Open its organisation details.
3. Find the response or opportunity status.
4. Select **Interested**.
5. Add relevant notes if the option is available.
6. Save the change.

The bank’s contact status remains **Contacted** because outreach has already occurred. **Interested** records the result of that outreach.

## 8. Generating an Email Draft

A valid recipient email address must be recorded before an email can be prepared or sent.

1. Open a **Not Yet Contacted** organisation.
2. Select the email or draft-email option.
3. Check the recipient’s email address.
4. Select **Generate Email**.
5. Wait for the draft to appear.
6. Review the recipient, subject and message.
7. Edit or personalise the message if needed.
8. Save or submit the draft.

Generating or editing a draft does not change the organisation’s status to **Contacted**.

### Regenerating a Draft

1. Review the generated email.
2. Select **Generate New Email** if you want another version.
3. Review the new version carefully.
4. Make any needed edits before submitting it.

### Writing an Email Manually

If email generation does not work:

1. Read the error message.
2. Try generating the email again.
3. If it still does not work, write the email manually.
4. Review the email.
5. Submit it through the usual approval process.

## 9. Staff: Submitting a Draft for Approval

1. Generate or write the email.
2. Review the recipient, subject and message.
3. Make any needed changes.
4. Select **Submit for Approval**.
5. Check that the status changes to **Pending Review**.

An email cannot be sent until an Admin approves it.

## 10. Admin: Reviewing a Draft

### Approving a Draft

1. Open the draft marked **Pending Review**.
2. Review the recipient, subject and full message.
3. Check that the information is accurate and appropriate.
4. Select **Approve**.
5. Check that the draft status changes to **Approved**.

An Admin can approve a draft they prepared or edited.

### Rejecting a Draft

1. Open the draft marked **Pending Review**.
2. Select **Reject**.
3. Enter a clear reason explaining what needs to change.
4. Submit the rejection.
5. Check that the status changes to **Rejected** or **Changes Requested**.

A rejected email cannot be sent.

## 11. Editing and Resubmitting a Rejected Draft

1. Open the rejected draft.
2. Read the Admin’s reason for rejecting it.
3. Select **Edit**.
4. Make the requested changes.
5. Review the updated email.
6. Select **Submit for Approval**.
7. Check that the status returns to **Pending Review**.

## 12. Editing an Approved Draft

Approval applies only to the content that was reviewed. If an approved email is edited:

1. Open the approved draft.
2. Select **Edit**.
3. Make the changes.
4. Save the updated draft.
5. Check that its status returns to **Pending Review**.
6. Submit it for approval again.

The edited email cannot be sent until it is approved again.

## 13. Sending an Approved Email

Both Admin and Staff users can send an approved email.

1. Open the approved draft.
2. Check the recipient, subject and message one final time.
3. Select **Send**.
4. Wait for the success message.
5. Check that the organisation changes to **Contacted**.
6. Check that the sent email appears in the organisation’s communication history.

If an Admin has already sent the email, a Staff user should see a message explaining that it has already been sent. The system should prevent the same approved email from being sent twice.

## 14. Recording Other Responses

After receiving a response, open the organisation and select the right outcome:

- **Interested:** The organisation responded positively.
- **Not Interested:** The organisation declined the opportunity.
- **Do Not Contact:** The organisation asked not to receive further communication.

An organisation marked **Do Not Contact** must not receive further outreach.

## 15. Troubleshooting

| Problem | What to do |
|---|---|
| I cannot log in | Check your email address and password. If the problem continues, contact an Admin. |
| I did not receive a password-reset email | Check your spam or junk folder. Wait a few minutes before requesting another email. |
| I cannot see **Add Organisation** | Only Admin users can add organisations. |
| I cannot see **Approve** or **Reject** | Staff users cannot access these controls. An Admin must review the draft. |
| The draft is still **Pending Review** | It will stay pending until an Admin approves or rejects it. |
| Email generation failed | Try again. If it still fails, write the email manually and submit it for approval. |
| I cannot generate an email | Check that the organisation has a valid recipient email and is not marked **Do Not Contact**. |
| The organisation already exists | Open the matching organisation instead of adding another record. |
| A possible duplicate warning appears | Review the matching record. Continue only if the organisations are different. |
| I cannot send the email | Check that the draft is approved and has not been changed since approval. |
| The email was not sent | Read the error message and try again. The organisation should remain **Not Yet Contacted** until the email is sent successfully. |
| The organisation is already **Contacted** | Review its email history before attempting further outreach. |
| No organisations appear | Clear the search and filters, then try again. |
| The page does not load | Refresh the page. If the problem continues, log out, log in again and contact an Admin. |
