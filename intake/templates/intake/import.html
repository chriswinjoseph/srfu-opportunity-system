Required import format

Show the detailed instructions

1. Worksheets

  • {{ guide.sheet_organisations }}: one row per organisation.
  • {{ guide.sheet_contacts }}: one row per contact (may be empty of rows, but the sheet and headers must exist).
  • Sheet names must match exactly, including the capital first letter. Other sheets are ignored.
  • Row 1 of each sheet holds the headers. Capital letters in a header do not matter; spelling and underscores do. Extra columns are ignored.
  • Maximum {{ guide.max_mb }} MB and {{ guide.max_rows }} rows per sheet. Formulas must already be calculated; type plain values.

2. How contacts link to organisations

Each organisation has a unique organisation_id on the {{ guide.sheet_organisations }} sheet. Every contact row repeats that value in its own organisation_id column. Several contacts may share one organisation_id: the organisation is created (or matched) once and each valid contact is attached to it. A contact whose organisation_id is not on the {{ guide.sheet_organisations }} sheet is reported and skipped. Contacts are matched by contact_id and by email within the same organisation, so importing the same file again does not create duplicates.

6. Accepted values

  • State: {{ guide.states|join:", " }} (or the full name, in any capitalisation).
  • Organisation type: Bank, Branch or Club (any capitalisation). Any other value holds the row for review and it is not imported.
  • TRUE / FALSE columns: TRUE, FALSE, Yes, No, Y, N, 1, 0. Anything else is read as blank.
  • Dates: an Excel date, 2025-01-31 or 31/01/2025. Anything else is read as blank.
  • Missing optional values: leave the cell empty. A blank or (unspecified) contact name is stored as empty, never as a name.
  • Email: must be a valid address. An invalid or missing contact email skips only that contact.

7. Previous outreach evidence (contact_status)

Only the detailed evidence on each contact decides the organisation's status. The workbook's overall_status is not copied, and "Partially Contacted" is never imported. One confirmed successful outgoing email makes the organisation Contacted. Replies are kept as evidence and never set Interested.

8. Branches and clubs

Add the organisation_type column and fill it for every row. A Branch needs parent_bank_name (and parent_bank_state if different) naming a bank that already exists; otherwise it is reported as incomplete. A Club may optionally name a supporting bank the same way.

9. What happens next

  • The file is checked first. Missing sheets or headers stop the import before anything is created, and the message names what to fix.
  • You then see a preview and must press Confirm and import. Rows with problems are listed with the row number, the field and what to do; valid rows are still imported.
  • Possible duplicates are held for your review and never merged automatically.
