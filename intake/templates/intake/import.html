One sheet with a row per organisation is enough. A CSV or other spreadsheet cannot simply be renamed to .xlsx; start from the template. A file that does not match is rejected with a message naming what is missing, and nothing is imported.

What to upload

Use one sheet named {{ guide.sheet_organisations }} with these columns in row 1: {% for h in guide.simple_headers %}{{ h }}{% if not forloop.last %}, {% endif %}{% endfor %}. Every row needs an organisation ID, a name and a state. Contact names, emails and status may be left blank. You may add other supported columns (listed on the template's Instructions sheet); the preview shows which columns will be imported and which are unsupported and ignored.

With several contacts in a row, separate them with a semicolon. A name is attached to an email only when the row has one name and one email; otherwise the emails are added without names and the row is flagged for review. The status column is kept for reference and never marks an organisation Contacted on its own; that needs outreach evidence (below) or an Admin's decision. The original two-sheet client workbook ({{ guide.sheet_organisations }} and {{ guide.sheet_contacts }}, with its outreach evidence) is still accepted.
